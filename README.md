# St. Jude Metropolitan Hospital Management System

A professional hospital management system built with React, TypeScript, Vite, and modern web technologies.

## Features

- Professional hospital dashboard
- Patient management
- Doctor management
- Appointment management
- Hospital departments
- Medical records
- Billing and payments
- Staff management
- Reports and analytics
- Responsive design
- Modern hospital interface

## Technologies

- React
- TypeScript
- Vite
- Tailwind CSS
- Modern UI components
